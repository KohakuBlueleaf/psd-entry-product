# n ≤ 3 與一般 n 的結構性差距

## Lean 骨架（已完成）

`MatrixIneq/Certificate.lean`：

- `structure Certificate (n)`：次數 `D`、係數函數 `c m s`，以及三個性質
  - `nonneg`：$c_m(s)\ge0$（$m\ge1$）；
  - `total`：$(n-1)c_0(s)-\sum_{m\ge1}c_m(s)\ge-\log F_n(s)$；
  - `circle`：單位圓周上 $|1-\sqrt{st}\,z|\le\exp\bigl(-[\tfrac12(c_0(s)+c_0(t))+\sum_m\sqrt{c_m(s)c_m(t)}\mathrm{Re}\,z^m]\bigr)$。
- `disc_of_circle`：用最大模原理把圓周上的不等式推到閉圓盤。
- `reducedAt_of_certificate : Certificate n → ReducedAt n`。
- `mainTheorem_of_certificates : (∀ n, Certificate n) → Statement.MainTheorem`。

全部無 `sorry`。所以主定理現在精確等價於「對每個 $n$ 構造一個 `Certificate n`」，剩下的全是單變數與雙變數的實分析。

## 差距在哪裡

| | $n=2$ | $n=3$ | $n\ge4$ |
| --- | --- | --- | --- |
| 正 $n$ 邊形的非平凡內積 $\cos(2\pi k/n)$ 的不同值個數 | 1（$-1$） | 1（$-\tfrac12$） | $\lfloor n/2\rfloor\ge2$ |
| 證書所需的最低次數（E2 的 LP，見下） | 1 | 1 | $n-2\ge2$ |
| 用到的正性 | $A\succeq0$ | $A\succeq0$ | $A^{\circ m}\succeq0$，$m\le n-2$（Schur） |
| 證書的形狀 | 切線 | 切線 | 過多個節點的 Hermite 內插 |
| 係數函數 | $\dfrac{s}{(1+s)^2}$ | $\dfrac{s}{1+s+s^2}$ | 含 $\log$（超越函數） |
| 圓周推到圓盤 | 平凡（只含 $\mathrm{Re}\,z$） | 平凡 | 需要最大模原理 |
| 能否去掉對數 | 能 | 能（AM–GM） | 不能 |
| 雙參數不等式 | 多項式恆等式 | 多項式恆等式 | 超越函數的不等式 |

所以**最低次數恰為 $n-2$**。這是差距的根源，可以分成三層：

1. **幾何層：距離類的個數。** $n\le3$ 時正 $n$ 邊形上任兩個不同頂點的內積只有一個值，證書只需在一個點與位勢相切。
   位勢對 $x=\mathrm{Re}\,z$ 是凸函數，切線自動在下方，Cohn–Kumar 的內容退化成「凸函數在切線上方」。
   $n\ge4$ 有至少兩個距離類，證書必須同時在多個點相切，次數至少 $n-2$。
2. **代數層：超越性。** 單一節點的切線係數是位勢的導數，為 $s$ 的有理函數。
   兩個以上節點的 Hermite 內插含位勢在不同節點的值之差，即 $\log\frac{1+s^2-2sx_k}{1+s^2-2sx_l}$。
   例：$n=4$、次數 2 的證書 $P_s(x)=\alpha+\beta x+\gamma x^2$，
   $\alpha=-\tfrac12\log(1+s^2)$，$\beta=\dfrac{s}{1+s^2}$，$\gamma=\log\dfrac{\sqrt{1+s^2}}{1+s}+\dfrac{s}{1+s^2}$。
   於是雙參數不等式 (★★) 從多項式恆等式變成含 $\log$ 與平方根的不等式，不能再用「平方差等於 $(s-t)^2$ 乘正多項式」這種論證。
3. **正性層：Hadamard 冪次。** $n\le3$ 只用 $A\succeq0$ 本身。$n\ge4$ 必須用 $A^{\circ m}\succeq0$（$2\le m\le n-2$）。
   這也解釋了帖子的說法：
   - **實矩陣容易**：實情形只需在線段 $[-1,1]$ 上比較，位勢在其上是凸的，$x^m$ 本身也是正定函數，證書空間大得多。
   - **秩一已知**：只需要圓周上的不等式，不需要推到圓盤內。
   - **複、高秩、一般 $n$ 困難**：三層同時出現。

## $n\le3$ 的證明沒有用到而一般 $n$ 需要的東西

| 需要的事實 | $n\le3$ | 一般 $n$ 的狀態 |
| --- | --- | --- |
| 內插多項式在位勢下方 | 凸性 | Cohn–Kumar（誤差公式加絕對單調性） |
| 係數非負 | 顯然 | Cohn–Kumar（需核對原文） |
| $c_0(e^u)$ 為凹 | 顯式 | 數值成立 |
| $c_m(e^u)$ 對數凹 | 顯式 | 數值成立 |
| $W\ge0$ | 多項式恆等式 | 數值成立到 $n=40$，最小值在 $x=-1$ |

## 觀察

- 偶數 $n$ 時 LP 在次數 $n-2$ 就達到目標（$x=-1$ 處只需單重相切，因為它是區間端點），比 Cohn–Kumar 的次數 $n-1$ 低一次。
  對這一族檢驗 (★★)（E16）：$n=4,6,8$ 成立；$n=10$ 在極小參數處出現 $-8.5\times10^{-17}$（相對值），不能確定是真的負值還是誤差。
  所以目前以 Cohn–Kumar 族（次數 $n-1$）為準，它到 $n=40$ 都沒有問題。
- $n=4$ 是第一個真正的一般情形：兩個節點（$x=0$ 與 $x=-1$），係數含 $\log$。它是檢驗任何一般證法的最小測試。
